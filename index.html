Генератор названий смазок

Собирает полное коммерческое название и краткое описание по логике «бренд + линейка + свойство + консистенция».

Название — коммерческое. Температурные пределы, состав и свойства подтверждаются технической документацией конкретного продукта; юридическая доступность названий проверяется отдельно.

Слово линейки (ROCK, CORE и т. д.) остаётся всегда. POLAR, SYN и MOLY добавляются после него по порядку: линейка → POLAR → SYN → MOLY → EP/NLGI. Пример: CORE EP 2 — обычная, CORE POLAR EP 2 — та же, но низкотемпературная.
